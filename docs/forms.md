# Microsoft Forms — intake forms

Both forms are filled by managers. Answers are mapped 1:1 to list columns by the intake flows (see `flows.md`).

## Form 1: Staffing Request

1. Requesting manager (name)
2. Manager e-mail
3. Extra e-mails to copy (manager / coordinator)
4. Department
5. Position
6. Work hours
7. Shift pattern
8. Opening reason: *Termination / Promotion / Headcount increase*
9. Replaced employee *(shown for replacements)*
10. Has the termination already happened? *Yes / No*
11. Will there be an internal promotion process? *Yes / No*
12. Posting type: *Internal / External / Both*
13. Notes

## Form 2: Personnel Change

1. Requesting manager (name) and e-mail
2. Change type: *Promotion with/without replacement · Transfer with/without replacement · Other*
3. Effective from (date)
4. Employee name and employee ID
5. Current position, department, hours and salary
6. New position, department, hours and salary
7. Is this linked to another employee's exit? *Yes / No*
8. Replaced employee, ID and hours *(conditional)*
9. Exit reason and exit date *(conditional)*
10. Notes

> Sections 8–9 use Forms branching, so they only appear when they apply.
